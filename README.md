## 📋 Changelog

This repository features an **automated daily changelog** that tracks all repository activities including:
- 🔄 Commits and code changes
- 📋 Issues opened and resolved
- 🎯 Pull requests merged and opened
- 📁 File modifications

### Viewing the Changelog

Check out [CHANGELOG.md](./CHANGELOG.md) to see the complete history of updates in GitBook-style format.

### Automated Updates

The changelog is automatically updated daily at 00:00 UTC via GitHub Actions. You can also:
- **Manual Trigger**: Run the workflow manually from the Actions tab
- **Manual Script**: Use `.github/scripts/update-changelog.sh` for local updates

### Changelog Format

Each daily entry includes:
- Recent commits with short hashes
- Resolved and new issues
- Merged and opened pull requests
- File activity statistics

All entries are formatted in a clean, GitBook-style markdown format with emoji icons for easy scanning.
